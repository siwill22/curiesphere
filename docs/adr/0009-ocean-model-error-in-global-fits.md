# Global fits carry an error term for the ocean model

In a global fit the fixed ocean model is the background everywhere, so its errors reach the residual worldwide. GCM-GLC absorbed them by fitting the noise amplitude (×1.53 the measured LCS-1 - MLI_SHA_2E difference). Global layout fits instead use the measured noise plus a background error carried by the ocean model's own columns. Its spectrum comes from the difference of two ocean models (GK07_NR against HM05_NR), and its amplitude is fitted by the evidence. This is the global form of DF's ring error (ADR 0007 amendment): it keeps the background's errors out of the comparison of continental layouts.

## Considered Options

- Measured noise only (DF's rule): rejected for global fits. Ocean-model errors would be pushed into continental patterns, mostly along margins, and would favour fine layouts.
- A fitted noise amplitude (GCM's rule): kept as a check for GCM with a layout, not as the main error model. It absorbs real continental variation as well as background errors, which blunts the layout test.
